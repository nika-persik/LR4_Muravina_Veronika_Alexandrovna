# Bookstore - WPF-приложение для онлайн-магазина книг

Приложение для книжного магазина с регистрацией, авторизацией, каталогом книг, корзиной и оформлением заказов. Разработано на C# (WPF), данные хранятся в SQL Server, работа с БД выполняется через Entity Framework.

## Визуальная демонстрация

Основные страницы приложения:

* **Авторизация** - вход по логину и паролю, а также возможность входа в качестве гостя.
* **Регистрация** - создание нового аккаунта пользователя с проверкой капчи и валидацией полей.
* **Каталог книг** - просмотр доступного ассортимента, поиск по названию и фильтрация по жанрам.
* **Корзина** - просмотр добавленных книг, автоматический подсчёт итоговой суммы и оформление заказа.
* **Заказы клиентов** - просмотр всех совершенных заказов и смена их текущего статуса (доступно только администратору).
* **Добавление / редактирование книги** - удобная форма с валидацией данных и возможностью быстрого добавления нового автора или жанра прямо из окна формы.

## Установка

1. Установите **Microsoft Visual Studio** со средствами разработки WPF и .NET Framework 4.7.2.
2. Откройте решение `Bookstore.sln`.
3. Подготовьте базу данных SQL Server `Online_bookstore`.
4. Укажите ваш сервер и точное название базы в строке подключения `Online_bookstoreEntities` в файле `App.config`.
5. Восстановите NuGet-пакеты (`EntityFramework 6.2.0`) и соберите решение.
6. Запустите приложение.

## Использование

1. Войдите в систему под своей учетной записью, зарегистрируйтесь или продолжите работу в режиме гостя.
2. На странице **«Каталог книг»** воспользуйтесь строкой поиска по названию или фильтром по жанру, чтобы найти нужную литературу.
3. Авторизованный пользователь может добавить понравившуюся книгу в корзину с помощью кнопки **«В корзину»**.
4. Откройте **«Корзину»**, проверьте состав и итоговую сумму, после чего нажмите **«Оформить заказ»**. Заказ сохранится в БД, а количество доступных книг на складе автоматически уменьшится.
5. Администратор может изменять каталог, а также просматривать заказы клиентов и менять их статус (*Новый*, *В обработке*, *Готов к выдаче*, *Доставлен*, *Отменен*).

### Тестовые аккаунты:

* **Администратор:** логин `Maria`, пароль `admin` (роль Администратор, `ID_role = 2`).
* **Пользователь:** логин `Alex`, пароль `user1` (роль Пользователь, `ID_role = 1`).

## Структура проекта

* `Pages` - страницы приложения и обработчики событий:
  * `AuthorizationPage` - окно входа и гостевого доступа.
  * `RegistrationPage` - форма регистрации с защитной капчей.
  * `BooksPage` - каталог книг с поиском, фильтрацией и разграничением прав доступа.
  * `AddBookPage` - форма добавления и редактирования книг.
  * `BasketPage` - корзина товаров и оформление покупки.
  * `OrdersPage` - панель управления заказами и смены их статусов.
* `Basket.cs` - статическое хранилище элементов корзины.
* `Windows` - диалоговые окна `AddAuthorWindow` и `AddGenreWindow` для быстрого добавления авторов и жанров.
* `Entities` - модель Entity Framework (`Model1.edmx`) и автоматически сгенерированные классы.
* `MainWindow.xaml` / `MainWindow.xaml.cs` - главное окно приложения с элементом `Frame` для навигации между страницами.
* `App.xaml.cs` - логика запуска приложения, хранение общего контекста базы данных (`App.Context`) и данных текущего пользователя (`App.CurrentUser`).
* `App.config` - конфигурационный файл с настройками подключения к SQL-серверу.

## Данные

Используется база данных `Online_bookstore` со следующими таблицами:
* `Users` - зарегистрированные пользователи.
* `Roles` - роли пользователей (пользователь, администратор).
* `Books` - каталог книг.
* `Authors` - авторы книг.
* `Genres` - литературные жанры.
* `Orders` - оформленные заказы.
* `Order_items` - позиции (состав) каждого заказа.

Вся работа с данными выполняется через **Entity Framework 6** с использованием **LINQ-запросов** без ручной конкатенации SQL-строк, что защищает приложение от SQL-инъекций. При оформлении заказа автоматически создаётся запись в таблице `Orders` и связанные строки в `Order_items`, а также пересчитывается и уменьшается поле `Stock_quantity` у соответствующих купленных книг.
